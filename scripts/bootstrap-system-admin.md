# دليل تهيئة وإعادة ربط حساب السيستم أدمن (marwan-desouky) بأمان وبدون أسرار

هذا الدليل يوضح المسار الرسمي والآمن لتهيئة أو إعادة ربط حساب مدير النظام الرئيسي (`system_admin` - `marwan-desouky`) في Supabase **بدون كتابة أي كلمة مرور في الشيفرة أو ملفات Git أو سجلات الأوامر، وبدون حذف أو تدمير أي بيانات مستخدمين**.

> ⚠️ **تنبيه أمني صارم:**
> يُمنع منعاً باتاً تشغيل أي سكريبتات حذف أو تصفير مثل (`reset_users` أو `DELETE FROM auth.users`). تم رفض وحظر أي محاولة لحذف المستخدمين أو إدراج كلمات مرور نصية في الهجرات (راجع `supabase/pending/rejected/README.md`).

---

## 1. المسار المعتمد لربط هوية مدير النظام (Session A Bootstrap)

إذا كان الحساب يحتاج إلى إنشاء جديد أو إعادة ربط مع مستخدم المصادقة `auth.users`:

### الخطوة 1: إنشاء مستخدم المصادقة في Supabase Auth
1. من لوحة تحكم **Supabase Dashboard**:
   - انتقل إلى **Authentication** -> **Users**.
   - اضغط **Add user** -> **Create user** (أو **Invite user** عبر البريد الإلكتروني).
   - البريد الإلكتروني المعتمد: `marwandesouqhi@gmail.com` (أو البريد المعتمد للمسؤول).
   - إذا تم إنشاء المستخدم مباشرة، قم بتفعيل **Auto Confirm User**.
   - أو أرسل دعوة / رابط تعيين كلمة المرور ليصل إلى بريد المسؤول ويقوم هو بتعيين كلمة مروره بنفسه وبشكل سري عبر واجهة GoTrue الآمنة.

### الخطوة 2: الحصول على معرف المستخدم `auth_user_id` (UUID)
- انسخ الـ `UUID` الخاص بالمستخدم المنشأ من جدول `Authentication -> Users`.

### الخطوة 3: استدعاء دالة التهيئة الأحادية الآمنة (One-Time Hardened Bootstrap)
الدالة `public.bootstrap_system_admin` التي أُنشئت في الجلسة A (`20261017130000_lockdown_privileged_functions_and_bootstrap.sql`) محصورة بصلاحية `service_role` وتضمن:
- عدم تكرار التهيئة وقفل الحالة في `system_bootstrap_state`.
- التحقق من تأكيد البريد الإلكتروني في `auth.users`.
- ربط صف `app_users` وتوليد كود الموظف النظامي `SYS-ADM-000001` دون مساس بأي بيانات مستخدمين آخرين.
- تسجيل عملية التهيئة في سجل التدقيق الأمني `audit_logs`.

يمكن تنفيذها في **SQL Editor** باستخدام دور الخدمة:
```sql
SELECT public.bootstrap_system_admin(
  'marwandesouqhi@gmail.com',  -- البريد الإلكتروني المؤكد
  'marwan-desouky',            -- اسم المستخدم
  'YOUR_AUTH_USER_UUID_HERE'::UUID -- المعرف الحقيقي من auth.users
);
```

## 2. إدارة واستعادة كلمة المرور (Password Recovery Flow)

في حال نسيان كلمة المرور أو الرغبة في تدويرها:

1. **إرسال رابط استعادة كلمة المرور عبر البريد (Password Recovery Email):**
   - من لوحة تحكم **Supabase Dashboard** -> **Authentication** -> **Users**.
   - ابحث عن المستخدم واضغط على القائمة (`...`) ثم اختر **Send Password Recovery**.
   - أو عبر استدعاء الإجراء الآمن `send_password_recovery` في دالة `admin-users` السحابية باستخدام توكن `service_role`.
2. يتلقى المسؤول بريداً إلكترونياً رسمياً يحتوي على رابط مؤمن ومحدد بوقت زمني لتعيين كلمة المرور الجديدة في المتصفح عبر Supabase Auth.
3. لا تمر كلمة المرور الجديدة عبر أي سيرفر وسيط أو ملف كود أو هجرة قاعدة بيانات.

## 3. تسجيل الدخول والتحقق

1. افتح شاشة الدخول في تطبيق الويب.
2. أدخل:
   - **المعرّف:** `marwan-desouky` أو البريد الإلكتروني.
   - **كلمة المرور:** كلمة المرور التي عينها المسؤول عبر رابط الاستعادة أو الدعوة.
3. يدخل المسؤول بكامل صلاحيات `system_admin`، وتظل كافة بيانات وحسابات النظام والعمليات محفوظة بالكامل دون أي مساس.
