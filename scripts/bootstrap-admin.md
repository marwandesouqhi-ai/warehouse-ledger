# دليل تهيئة حساب مدير النظام (Bootstrap System Admin — Legacy Notice)

> ⚠️ **تنبيه أمني:** تم إيقاف استخدام أي سكريبت SQL يدوي يُدخل صفوفاً مباشرة في `auth.users` أو يستخدم `crypt()` أو يُنشئ حسابات بنطاقات وهمية (`@warehouse.local`) أو بدور `'admin'`.
> يجب اتباع الدليل الرسمي الآمن في [bootstrap-system-admin.md](./bootstrap-system-admin.md) واستخدام الدالة المحمية `public.bootstrap_system_admin(...)` بعد إنشاء المستخدم عبر **Supabase Dashboard (Authentication -> Users)** أو عبر استدعاء `service_role`.

---

## ملاحظات هامة حول الاتصال والعمل دون إنترنت (Offline / PWA)
1. **تسجيل الدخول الأول:** يتطلب اتصالاً بالسحابة (Supabase Cloud) للتحقق من هوية المستخدم وتوليد رمز الجلسة المشفر (JWT).
2. **وضع عدم الاتصال (Offline PWA):** يدعم استمرار العمل على الجلسة الحالية النشطة والتخزين المؤقت، ولكنه **لا يدعم تسجيل دخول جديد لأول مرة** دون اتصال بالإنترنت.
