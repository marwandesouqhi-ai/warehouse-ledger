هل نحوّل واجهة النظام إلى Glassy؟ نعم، بشروط وفي أماكن محددة

الزجاجية (شفافية مع blur خلف السطح) تعطي النظام شكلاً أحدث وعمقاً بصرياً، لكنها تضرّ بقراءة الجداول والنماذج لو عُمّمت. التوصية: نطبّقها على الأسطح «الإطارية» (القائمة والشريط العلوي والكروت العلوية والنوافذ) ونترك الجداول والحقول على أسطح مصمتة. جرّب القيم بنفسك في المختبر أدناه.

الخلاصة

ثلاثة قرارات تحدد نجاح التحويل.

يُطبَّقالإطار والتنقلالقائمة الجانبية، الشريط العلوي، الشريط السفلي على الموبايل، النوافذ المنبثقة، وكروت المؤشرات العلوية.
لا يُطبَّقالجداول والنماذجالجداول وحقول الإدخال وسجل الحركات تبقى على أسطح مصمتة: القراءة والدقة أهم من الشكل في الشاشات المحاسبية.
بشرطتباين وأداءنسبة تباين ٤٫٥:١ على أسوأ نقطة في الخلفية، وبديل مصمت للأجهزة الضعيفة ولمن يفضّل تقليل الشفافية.

مختبر الزجاج

غيّر الـ blur والشفافية ونسبة الحافة. النسب تُحسب على أسوأ نقطة في الخلفية (أفتح أو أغمق لون في التدرّج)، لأن النص الزجاجي يُقرأ على ما خلفه وليس على لون السطح وحده.

أين نطبّق الزجاج وأين لا

القاعدة: كل ما يحمل أرقاماً يُقرأ ويُقارَن يبقى مصمتاً.

العنصرالقرارالسبب
القائمة الجانبية والدرج على الموبايلزجاجعناصر تنقل بنص كبير، والخلفية خلفها ثابتة.
الشريط العلوي والشريط السفليزجاجيطفوان فوق المحتوى، والـ blur يفصلهما بصرياً دون حدود ثقيلة.
كروت المؤشرات العلوية (KPI)زجاجأرقام كبيرة بخط عريض، فتتحمل الشفافية.
النوافذ المنبثقة (Modals)زجاج خفيفالخلفية المموّهة تحافظ على السياق، لكن الحقول داخلها مصمتة.
الجداول وسجل الحركات والجردمصمتمقارنة أرقام صف بصف؛ أي تدرّج خلفي يشوّش القراءة.
الفورمات وحقول الإدخالمصمتالحدود والتركيز يجب أن يكونا واضحين في كل الظروف.
الطباعة والتقارير الرسمية (A4)مصمتالطباعة لا تدعم backdrop-filter وتحتاج أبيض نقياً.

المخاطر وكيف نتفاداها

تبايننص يضيع فوق خلفية فاتحة أو غامقةنختبر النسبة على أسوأ نقطة في التدرّج، ونرفع شفافية السطح لـ ٦٠٪ على الأقل في النصوص الصغيرة.
أداءbackdrop-filter مكلف على الأجهزة الضعيفةنحدّ عدد الطبقات الزجاجية في الشاشة (٥–٦ كحد أقصى)، ونتجنب blur أكبر من ٢٠px، ونعطّله عند prefers-reduced-transparency.
توافقمتصفحات بلا دعم أو وضع توفير الطاقةنكتب القيمة المصمتة أولاً، ونضيف الزجاج داخل @supports فقط، فلا يتغير شيء لمن لا يدعمه.
اتساقخلط الزجاجي والمصمت عشوائياًنعرّف ثلاثة مستويات فقط (مصمت، زجاج، زجاج خفيف) كتوكنات، ولا يُسمح بقيم شفافية حرفية داخل المكوّنات.

التوكنات المقترحة

تتوافق مع أسماء المتغيرات الحالية في index.css (--surface, --line) وتُضاف فوقها دون تغيير المكوّنات القائمة.

index.css
/* 1) Solid defaults first (works everywhere, incl. print and old browsers) */
:root {
  --glass-bg: var(--surface);
  --glass-border: var(--line);
  --glass-shadow: var(--shadow-sm);
  --glass-blur: 0px;
}

/* 2) Glass only where backdrop-filter is supported */
@supports ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  :root {
    --glass-bg: rgba(255, 255, 255, 0.62);
    --glass-border: rgba(255, 255, 255, 0.55);
    --glass-shadow: 0 8px 32px rgba(16, 37, 39, 0.12), inset 0 1px 0 rgba(255, 255, 255, 0.45);
    --glass-blur: 16px;
  }
  :root[data-theme='dark'] {
    --glass-bg: rgba(17, 26, 44, 0.58);
    --glass-border: rgba(255, 255, 255, 0.10);
    --glass-shadow: 0 8px 32px rgba(0, 0, 0, 0.45), inset 0 1px 0 rgba(255, 255, 255, 0.08);
  }
}

/* 3) One utility, used only on frame surfaces */
.glass {
  background: var(--glass-bg);
  border: 1px solid var(--glass-border);
  box-shadow: var(--glass-shadow);
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(160%);
  backdrop-filter: blur(var(--glass-blur)) saturate(160%);
}

/* 4) Respect users who ask for less transparency */
@media (prefers-reduced-transparency: reduce) {
  :root, :root[data-theme='dark'] {
    --glass-bg: var(--surface);
    --glass-border: var(--line);
    --glass-blur: 0px;
  }
}

/* 5) Page background that gives the glass something to blur */
body {
  background:
    radial-gradient(900px 600px at 85% 0%, color-mix(in srgb, var(--accent) 22%, transparent), transparent 70%),
    radial-gradient(900px 700px at 0% 100%, color-mix(in srgb, var(--info) 18%, transparent), transparent 70%),
    var(--bg);
  background-attachment: fixed;
}

/* Apply to: .sidebar, .topbar, .mobile-bottom-dock, .kpi-card, modal panels.
   Never to: tables, inputs, print styles. */

خطة التنفيذ

كل مرحلة قابلة للتراجع بمفردها.

  1. التوكنات والخلفيةإضافة متغيرات الزجاج والخلفية المتدرجة مع البديل المصمت، دون لمس المكوّنات.
  2. الإطار والتنقلتطبيق .glass على القائمة والشريطين والدرج، واختبار التباين في الوضعين.
  3. الكروت والنوافذكروت المؤشرات والنوافذ المنبثقة، مع إبقاء الحقول والجداول مصمتة.
  4. التدقيق والأداءقياس الأداء على جهاز متوسط، وإضافة مفتاح «تقليل الشفافية» في الإعدادات.
